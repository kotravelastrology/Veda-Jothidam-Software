## Source check

- **Ch.27 v.13 (file p.222-224, printed p.212-214): the rule and its own fully worked example** (birth = June 1, 1984). Four fixed Virupa awards -- Varsha (year) lord 15, Masa (month) lord 30, Dina (day) lord 45, Hora (hour) lord 60 -- each going to whichever planet rules a specific weekday, determined via an "Ahargana" (elapsed-day count) arithmetic procedure.
- **Varsha lord — a resolved rule/example contradiction.** The rule's own prose says "divide...by 60," but the very same passage's fully worked example only reproduces its own stated final answer (remainder 5 -> Thursday -> Jupiter) when the divisor is 360: reproduced every intermediate step by hand (65295÷360 -> quotient 181; 181×3+1 -> 544; 544 mod 7 -> 5) and it matches the book's own printed numbers exactly. Treated as a transcription slip (a dropped "3"), the same kind of resolution already used for Ojhayugmarasyamsa Bala's "5 Virupas" parenthetical in S10 -- not a second convention, not a guess.
- **Masa and Dina lord** -- both directly and unambiguously confirmed by reproducing the worked example's arithmetic exactly (Masa: 65295÷30 -> 2176; ×2+1 -> 4353; mod 7 -> 6 -> Friday -> Venus; Dina: 65295 mod 7 -> 6 -> Friday -> Venus), with no rule/example discrepancy.
- **The "Abbreviated Ahargana" epoch** -- rather than hand-transcribing the multi-page printed "Speculum of Abbreviated Ahargana" lookup table (error-prone for a purely numeric scanned table, and limited to whatever year range it happens to print), the epoch offset was derived directly from the chapter's own prose statement ("for January 0 date 1984, [Abbreviated Ahargana] is 65142") combined with a Julian Day calculation ("January 0" = Dec 31, 0h UT of the previous year, the same 19th-century almanac convention the passage's own cited source, Ebenezer Burgess's Surya Siddhanta translation, uses). **Cross-verified against a second, independently-read row of the same printed table, 124 years apart** (1860 -> 19852): `JD(Jan 0, 1860) - 2380557.5 = 19852.0` exactly, with no adjustment. Two independent exact matches from the book's own numbers is treated as sufficient computational verification, in the same spirit as reproducing Uchcha Bala's worked example in S10.
- **Hora lord** -- the verse's own description ("the 2nd [Hora] is ruled by the lord of the 6th weekday counted from the first ruler") was initially miscoded as a "-1 step" (treating "6th" as an offset of 6), which a hand-check against the universally-known Chaldean planetary-hour sequence for Sunday (Sun, Venus, Mercury, Moon, Saturn, Jupiter, Mars) caught as wrong. Corrected to a "+5 step" once "6th counted from" is read as inclusive counting (the starting weekday itself is the "1st"). Verified against the full 7-position Sunday sequence.
