## 1. MAIN SCREEN (Birth Chart I - Screen 1)

PL9 main screen layout has 6 panels:

| Panel | Position | Content |
|-------|----------|---------|
| **Birth Chart** | Top-left (large) | South Indian square chart with planets showing degree + nakshatra abbreviation (e.g., "Mo 23:56 Rev", "Ma 19:05 Roh") + house boundary degrees |
| **D9 Navamsha** | Top-right | Smaller South Indian chart labeled "(spouse)" |
| **Vimshottari Dasha** | Right side | Scrollable list with +/- buttons showing Mahadasha-Bhukti pairs and dates (Su-Ra Wed 19-08-2026, Su-Ju Wed 14-07-2027...) |
| **Planetary Positions** | Bottom-left | Table: Planet, Degree, Nakshatra Pada, Rashi, Friends/Enemies |
| **Shadbala Table** | Bottom-center | Table: Dignity, SB%, SB#, MB, VB, AV, Av3, Av5 columns |
| **Shadbala Bar Chart** | Bottom-right | Visual bar chart with colored bars for each planet (green=strong, red=weak) |

**Key Features of Main Screen:**
- House cusp degrees shown on all 4 sides of the chart (e.g., "8th h. 24 543.96")
- Planet abbreviations color-coded (Su=red, Mo=black, Ma=red, Me=green, Ju=orange, Ve=green, Sa=blue, Ra=black, Ke=black)
- Gulika (Gk) shown as additional point
- Nakshatra abbreviations: Rev=Revati, Roh=Rohini, Pus=Pushya, Has=Hasta, etc.
