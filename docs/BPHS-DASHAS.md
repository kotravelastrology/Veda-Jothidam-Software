# BPHS chapter 46 nakshatra dashas

Page `/bphs-dashas`; engine `src/dasha/bphsDashas.js`; test `test-bphs-dashas.js`.
Source: Brihat Parashara Hora Sastra, Santhanam ed., ch.46 vv.17-43 (printed pp.409-417; PDF page = printed + 7).

- Ashtottari: rebuilt on the book's 28 divisions (with Abhijit 276°40'-280°53'20"). The old 4,3,4,3,4,3,4,2 split gave wrong lords for Dhanishta-Krittika and is replaced.
- Shodashottari, Dwadashottari, Panchottari, Shatabdika, Chaturashiti-sama, Dwisaptati-sama, Shat-trimshat-sama: SOURCED, with the book's worked examples as tests.
- Chaturashiti-sama: printed example (Mars) contradicts the printed rule (Mercury); both recorded, rule used.
- Shastihayani: DECLARED, not built - the table is cut off in the scan and editions disagree (Chitra missing, Sun 4 vs 3 stars).
- Each system shows the applicability condition the verse names, checked against the chart; Parashara says Vimshottari is main for all.
- Antardashas are proportional as in Vimshottari (no separate rule printed).
- Remaining in ch.46: rashi dashas (Chara, Sthira, Navamsha, Narayana, Shoola, Drig, Kendradi, Padanadhamsa, Yogardha).
