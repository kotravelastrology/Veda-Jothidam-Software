## Source check — calculation

- **Nathonnata Bala** (BPHS v.8-9, file p.221, plus the "simple method" note in the same passage): re-examined the S10 caution that the Ghati-based method and the simple degrees-from-midnight method might be conflicting conventions. On closer reading, they describe the **same elapsed-time fraction in different units**, not two different rules — S10's original deferral was overcautious. Implemented: Unnata = elapsed time from the nearest local midnight (0-30 ghatis / 0-12 hours either side); Nata = 30 ghatis − Unnata; Moon/Mars/Saturn get 2×Nata; Sun/Jupiter/Venus get 60 − that; Mercury always gets the full 60 regardless of birth time. Verified by hand at both boundary cases (exact local midnight, exact local noon) for all seven planets.
- **Ayana Bala** — re-read v.15-17 specifically looking for a way to unblock it, and found a **genuine, precise source-internal inconsistency** rather than just "not yet implemented": the translator's own "simple formula" note gives `Ayana Bala = ((23°27′ + Kranti) × 60) ÷ 46°54′`, but that same note's own worked "Speculum of Ayana Bala" table does not match this formula. Hand-checked multiple table rows against the formula (e.g. Kranti 5°10′ → table gives 6.6, but the printed formula gives ≈36.6; 6.6 only comes out of `Kranti × 1.2793` directly, with no `23°27′` addition at all) — visually confirmed via rendered page images of the table pages. Since the book contradicts itself, this is refused with the specific inconsistency recorded, not guessed either way.
- **Cheshta Bala** (non-Moon) and **Drik Bala** — re-read v.19 and v.24-25 to sharpen the deferral reasons: Cheshta needs classical mean longitude + Seeghrocha (a Siddhantic mean-motion/epicycle apogee model, not a modern-ephemeris quantity); Drik needs Drishti Pinda, a per-pair aspect-strength table not yet located.
- **Yuddha Bala** (v.20, file p.233-234) — newly read this stage (S10 had not reached it at all). It is a planetary-war post-hoc adjustment to an already-complete total, not an independent additive component, and needs a war-detection rule (which two planets count as "at war," and which one wins) not yet verified. Added as its own explicit `sourceRequired(...)` field rather than silently omitted.
- **Bhava Bala** (house strength) — found a complete, admitted-source definition in *Practical Ashtakavarga* (Vinay Aditya), Ch.4, already on file from the S9 Ashtakavarga work: "whether a house is powerful or not, as far as Ashtakavarga is concerned, we should see by: (1) the sarvashtaka bindus earned by the sign falling in the house; (2) the sarvashtaka and bhinnashtaka bindus of the lord of the house; (3) ...of the karaka of the house." Visually verified against the rendered source page. The source gives three factors to read together, not a combining formula, so all three are returned separately per house — matching the same honest, non-invented-formula pattern already used for S9's Ashtakavarga Transit.
- **Shodasa Bala / Vimshopaka Bala** — searched the admitted corpus for an exact point table. Vinay Aditya's book (Ch.4) names the concept and its purpose (a 16-varga, dignity-weighted composite strength) but explicitly defers the point table itself to a different, not-yet-catalogued book (K.S. Charak). **No exact table has been verified**, so this remains a named, honest gap rather than a guessed or borrowed table.

## Source check — competitor UI/UX (per standing instruction)

Checked both reference products for this specific feature, as required before building any new UI:

- **Parashara's Light 9** — could not be run directly (Windows desktop software, not installed), so checked via its own documentation/reviews. Its "Bala Panel" (Charts & Tables → Shadbala) draws each planet's total Shadbala as a **horizontal bar with a visible minimum-strength threshold zone** — bars ending past the line read as strong (shown in green), short of it as weak (shown in red). This is a well-established, legible convention worth adopting for the bar's *shape*.
- **Cosmic Insights** — its own blog ("How to Interpret Bhava Bala in Vedic Astrology," cosmicinsights.net) confirms Bhava Bala is presented as a per-house strength reading, consistent with the table-per-house approach already planned here; nothing UI-specific beyond that was found in the time available.
- A third, directly-browsable Shadbala calculator (ishvaram.com) was also checked as a live UI reference and turned out to be informative for a different reason: it explicitly states "the Ishvaram engine currently computes 0.0 for this source pending full implementation" for its own unfinished components (Kala, Drik). That is a **weaker** honesty convention than this project's `ஆதாரம் தேவை` badge — a silent `0.0` can be misread as "this planet genuinely has zero strength here," whereas an explicit badge cannot be mistaken for a real value. This project's existing convention is kept as-is on this evidence, not changed to match the competitor.

**Decision made from this check:** adopt Parashara's Light 9's *visual threshold marker* on the bar (a dashed line at the classical minimum-Rupa point, per planet, per BPHS v.32-36), but **not** its green/red strong/weak verdict coloring — because our bar is a labelled *partial* sum (Saptavargaja/Ayana/Varsha-Masa-Dina-Hora/most-Cheshta/Drik/Yuddha are still missing), and a red "weak" reading on an incomplete total would misrepresent a planet that is only *unmeasured*, not actually weak. The marker is kept purely comparative, with its own on-hover explanation.
